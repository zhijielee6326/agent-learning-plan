## 💡 学习建议

### DO ✅

1. **动手实践** - 每个知识点都要亲自写代码
2. **循序渐进** - 按难度顺序学习，不要跳级
3. **记录笔记** - 在每个知识点文件中记录自己的理解
4. **提问讨论** - 遇到问题及时在小组中讨论
5. **构建项目** - 最终目标是完成一个完整应用

### DON'T ❌

1. **只看不练** - 看懂了不代表会写了
2. **孤立学习** - 小组学习的效果更好
3. **追求完美** - 先跑通，再优化
4. **忽略基础** - 基础不牢，后续会吃力
5. **害怕错误** - Debug 是学习的一部分

## 🐛 获取帮助

### 遇到问题时

1. **查看文档** - 技术栈的官方文档
2. **检查错误** - 参考每个知识点的"常见问题"部分
3. **搜索社区** - GitHub Issues, Stack Overflow
4. **小组讨论** - 在学习小组中提问
5. **官方支持** - 各框架的 Discord/社区

### 常见问题汇总

| 问题 | 解决方案 |
|------|----------|
| 安装失败 | 清理缓存，使用 pnpm |
| API 不工作 | 检查 API Key 和模型格式 |
| 类型错误 | 查看最新文档，不要依赖记忆 |
| 性能问题 | 检查 Token 使用，考虑缓存 |
